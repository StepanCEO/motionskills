Что входит в дизайн-проект

Дизайн-проект — архив с файлами для создания вертикальных роликов 9:16 (Reels, Shorts, TikTok) с помощью Claude. Каждый проект выполнен в своём визуальном стиле.

Инструкции для Claude

Описание стиля, правила анимации и готовые запросы, по которым Claude собирает ролик.

Шаблон видео

Готовый шаблон ролика: титры, переходы и анимации, которые остаётся наполнить своим текстом и материалом.

Звуки, шрифты и цвет

Звуковые эффекты, шрифты и цветовые пресеты, подобранные под стиль проекта.

Лицензия

Право использовать проект в своих роликах, в том числе коммерческих, — по условиям оферты.
